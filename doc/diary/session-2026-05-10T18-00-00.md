## 8. Bresenham vs plan — switch to **DDA**

- Plan/spec explicitly prefer **DDA-style** line stepping (float increments acceptable).
- **`draw_line`** was rewritten from **Bresenham** to **parametric DDA:**
  - **`steps = max(|Δx|, |Δy|)`** in integer space,
  - **`t = i / steps`** for **`i = 0..=steps`** ( **`t = 0`** when **`steps == 0`** ),
  - **`(x, y) = (x0 + dx·t, y0 + dy·t)`** in **`f64`**, **`round`**, then **`set_pixel`**,
  - negative rounded coords skipped before **`as u32`** cast.

Doc comment on **`draw_line`** updated accordingly.
