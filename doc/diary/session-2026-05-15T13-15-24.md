## `model_matrix_still` as `const` (design + WIP)

- **`Mat3::from_rotation_*`** in **`glam` 0.32** is **not** **`const fn`**, so the existing construction is not **`const`** as-is.
- **`Mat4::from_cols_array`** **is** **`const`**: the still matrix can be spelled with **`K = std::f32::consts::FRAC_1_SQRT_2 * 0.5`** and **`±0.25`** entries (verified numerically against **`model_matrix_still().to_cols_array()`** in a one-off panic dump: column-major **16** floats).
- A unit test using **`approx::assert_relative_eq!`** on **two `[f32; 16]`** arrays **failed to compile** (**`RelativeEq`** not implemented for **`[f32; 16]`** in **`approx` 0.5**); fix would be per-element loops or compare as slices **`&[f32]`**.
- **At diary write time**, **`src/wireframe.rs`** on disk still exposes **`pub fn model_matrix_still() -> Mat4`** (no **`MODEL_MATRIX_STILL`** const); bins still call **`model_matrix_still()`**.
