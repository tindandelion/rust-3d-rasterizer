## Conceptual: `visible_edges` and `EDGE_FACE_PAIRS`

- **`EDGE_FACE_PAIRS[k]`** pairs two **facet indices** (into the six faces) that share hull **edge `k`** (parallel to **`EDGE_INDICES[k]`** in the older table-driven implementation).
- **Option A:** emit a hull segment iff **not** **(both** incident facets strictly back-facing**)** — i.e. draw the edge if **at least one** adjacent face is front-facing or edge-on (**`n · view == 0`** is **not** treated as back).

| Stage | Behavior |
|-------|----------|

## `visible_edges` vs `_visible_edges` (analysis)

- **Table-driven** path: walk the **12** fixed **`EDGE_INDICES`** and drop an edge when **both** incident facets (via **`EDGE_FACE_PAIRS`**) are back — **one** entry per hull edge, fixed **`(i,j)`** order from **`EDGE_INDICES`**.
- **Facet-union** path: for each **non–back** face, insert all **`CubeFace::edges()`**; shared edges appear from **two** facets with **opposite** orientation **`(a,b)`** vs **`(b,a)`**.
- **Bug:** raw **`HashSet<(usize,usize)>`** treats **`(a,b)`** and **`(b,a)`** as distinct → **duplicate** geometric edges when **both** adjacent faces contribute.
- **Fix:** canonicalize keys **`(min(a,b), max(a,b))`** before **`insert`**.

**Final committed code:** **`visible_edges`** implements the **facet-union + undirected dedup** approach (static **`EDGE_*`** tables removed from this file in favor of **`CubeFace::edges()`**). Module docs still mention **`EDGE_INDICES`** / **`EDGE_FACE_PAIRS`** in places — worth a follow-up doc sync if those symbols no longer exist in **`cube.rs`** (they may be stale references).
