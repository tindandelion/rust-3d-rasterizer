## Major decisions

### Library + thin binaries

- **`src/lib.rs`** exposes **`framebuffer`**, **`ortho_camera`**, **`scene`**, **`webp_encoder`** plus **`pub use`** of **`FrameBuffer`**, **`Rgb`**, **`Camera`**, **`WebpEncoder`**.
- Entry **`src/main.rs`** removed; **`still-cube`** lives under **`src/bin/still-cube.rs`** with **`Cargo.toml`** **`default-run = "still-cube"`**.

### Crate and binary naming

- Package name **`thorus-forge`** (Rust identifier **`thorus_forge`**).
- Demo binary **`still-cube`** (**`CARGO_BIN_EXE_still-cube`**): integration **`tests/common/mod.rs`** uses **`INTEGRATION_TEST_BIN = "still-cube"`** because the exe name differs from **`CARGO_PKG_NAME`**.

### Module layout convention

- **`src/scene.rs`** + **`src/scene/cube.rs`** (**parent.rs + parent/child**), not **`scene/mod.rs`**.
- Documented preference in **`AGENTS.md`** (avoid new **`mod.rs`** in **`src`** without good reason).

### Scene geometry (**`scene::cube`**)

- **Unit cube** corners in **`UNIT_VERTS`** (**edge length 1**, ±0.5).
- **`Cube`** holds **`Mat4`** via **`set_transform`**. **`edges()`** yields **`Edge(Vec3, Vec3)`** in **world** space after **`transform_point3`**.
- **Wireframe raster** ( **`Camera::transform`** + framebuffer **`draw_line`**) deliberately lives in **`still-cube`**, not in **`scene/cube.rs`**, to keep scene math separate from raster/camera coupling.

### Transforms in **`still-cube`**

- **`cube_transform() -> Mat4`**: uniform scale **0.5** on unit cube (world edge **0.5**, matches golden snapshot) then **π/4** rotations **Y** then **X** ( **`rot * scale`** → **`Mat4::from_mat3`** ).
- Separate **`WORLD_EDGE`** constant dropped in favor of inline **`0.5`** plus comments.

### Shared defaults (**Pt 3**)

- **`SCENE_WIDTH` / `SCENE_HEIGHT`** (**800 × 600**) and **`DEFAULT_OUT_PATH`** (**`scene.webp`**) as **`pub const`** on **`thorus_forge`** (**`src/lib.rs`**). User preference: **no** standalone **`src/config.rs`**.
- **`non_square_viewport_preserves_equal_axis_span_in_pixels`** uses **`crate::SCENE_WIDTH` / `SCENE_HEIGHT`**.
- **`tests/cube_snapshot.rs`**: reads golden first, asserts dimensions **`(SCENE_WIDTH, SCENE_HEIGHT)`**, then compares pixels.

### **`refactoring_plan.md`**

- Removed completed “high leverage” checklist items.
- Added **current layout** table and **observations** (e.g. **`draw_wireframe`** duplication → future generic helper; **`INTEGRATION_TEST_BIN`** when more bins exist).
- Reprioritized remaining ideas: **(1)** generic wireframe helper, **(2)** pipeline stages, **(3)** framebuffer accessors / test layout, **(4)** WebP write errors, **(5)** defer **`ortho_camera`** rename until perspective.
