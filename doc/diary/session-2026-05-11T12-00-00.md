## 2. First implementation pass (now removed by user)

**Note:** the user later **deleted the implementation** but kept docs, tests, and outputs. The following is what was built in this session so they can reproduce it step by step.

### Stack and modules (as built)

- **`glam`** — `Mat4`, `Vec3`, `Mat4::look_at_lh`, `Mat4::orthographic_lh`, `Mat4::from_rotation_y`.
- **`src/vertex.rs`** — `Vertex { position: Vec3 }`.
- **`src/cube.rs`** — unit cube **[-1,1]³**, **`TRIANGLE_INDICES`** (12 triangles, two per face), **`triangles()`**, **`wireframe_edge_indices()`** (unique triangle edges, then filter to **axis-aligned hull** edges only — **12** edges, **six** face diagonals dropped).
- **`src/transform.rs`** — **`OrthoScene`**: `MVP = P * V * M`, viewport NDC→pixel with **Y flip** (row 0 = top). Camera **eye (2.7, 2.1, −4.2)**, target origin, up **Y**; ortho **±2.6**, near **0.5**, far **25**; model **rotation Y = 20°** (user requested replacing an earlier multi-axis Euler stack).
- **`src/framebuffer.rs`** — **`draw_line_f`** with fractional endpoints, **`steps = ⌈max(|Δx|,|Δy|)⌉`**, skip-only OOB; earlier `Point`/`draw_line` API was folded into **`draw_line_f`** for tests + wireframe.
- **`src/main.rs`** — assert triangle count vs indices; draw wireframe; WebP encode.

### Design tension and resolution

- Initial shortcut used a **hand-maintained 12-edge list**, which conflicted with the spec’s **triangle-stream** boundary.
- Refactor: **indexed triangle soup** + **`Vertex`** + wireframe derived from triangles + **model-space** axis-aligned filter so triangulation diagonals are not drawn.

### Golden image and metadata

- Snapshot **`snapshots/cube/scene.webp`** (800×600 lossless) used for integration comparison.
- **`snapshots/cube/scene.json`** added: machine-readable scene parameters (conventions, camera, ortho, model rotation, mesh vertices/triangles, wireframe rule, viewport formulas, raster notes, export) so an independent reimplementation can match the reference.
