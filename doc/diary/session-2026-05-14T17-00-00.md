## Decisions and simplifications (chronological arc)

### Unit NDC / frustum

- Assumed scene **fits `[-1, 1]`** per axis for **x/y** raster placement.
- Dropped **general axis-aligned ortho** API: **`vmin` / `vmax`**, **`orth_projection`**, **`orth_projection_matrix`**, **`UNIT_LO` / `UNIT_HI`** in tests.
- **Proj** treated as **identity** for the stripped-down path (no separate matrix multiply at call sites for the final design).

### Depth

- Removed **NDC z → linear01**, **`u16`** pack/unpack, and integration cases that exercised depth.
- **`z`** does not participate in **xy** screen mapping (later: **`project`** ignores **`world_point.z`** for pixels).

### Clamping

- Removed **`clamp_float_pixel_xy`** and any “snap to border” step in composed pipelines so **line clipping** is not fooled by endpoints pulled to **`x = 0`** or **`x = width−1`**.
- **Quantize** still uses **`f32::round`** then **`as u32`** (non-saturating; negatives can **wrap**).

### Fixed camera

- **Eye `(0, 0, −1)`**, **target origin**, **+Y up**, **left-handed**, **+Z forward** (aligns with planning docs / `look_at_lh` intuition).
- **Translation-only view:** **`view_xy = world_xy`**, **`view_z = world_z + 1`**; raster path used **`world.x` / `world.y`** directly as the NDC-style **xy** input.

### Public surface shrinkage (intermediate steps in chat)

- At one point **`world_to_framebuffer_pixel`** was the **only** **`pub`** export from a **`projection`** module, with integration tests calling **only** that function and test-local helpers **`world_xy` / `world_xy_for_float_pixel`**.
- User later **restructured** the repo: **no `lib.rs`**, binary **`main.rs`** with **`mod ortho_projection`**.
