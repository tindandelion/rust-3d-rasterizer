## 2. Orthographic mapping: `Mat4`, non-zero viewport

- Replaced scalar **`project(...)`** math with **`ndc_viewport_matrix` → `Mat4`**, applied as **`m * world_point.extend(1.0)`**, then **`round`** / **`as u32`** on **xy** → **`UVec2`**.
- Compose order (column vectors): **`Mat4::from_translation(...)` * `Mat4::from_scale(scale, -scale, 1)`** — scale first on **`v`**, then translate; **y** flip for bitmap **+y** down.
- **Precondition:** **`assert!(width > 0 && height > 0)`** (no silent **`(0,0)`** return for empty viewports).
