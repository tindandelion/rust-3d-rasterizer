## Design decisions (chronological)

1. **`CubeFace`** — holds **model-space** unit **`normal`** and quad **`verts: [usize; 4]`** into an internal **`UNIT_VERTS`** table. **`FACES`** lists six faces; **`EDGE_FACE_PAIRS`** maps each of the twelve **`EDGE_INDICES`** hull edges to two face indices.

2. **Facing rule** — treat face as back-facing when **`n · camera_forward < 0`**; **`dot == 0`** is **not** back-facing (silhouette / edge-on stays drawable unless **both** sides are strictly back).

3. **`CubeFace::transform(model_to_world)`** — **only** transforms **`normal`** via **`Mat4::transform_vector3`** + **`normalize`**; **`verts`** stay indices (user explicitly did **not** want corner positions duplicated/transformed on the face value).

4. **`CubeFace::is_back(camera_forward)`** — uses **`self.normal`** (expected **world**-space after **`transform`**) for the dot test.

5. **`Cube::visible_edges`** — classifies each **`FACES`** entry with **`face.transform(cube_matrix).is_back(forward)`**, then filters **`EDGE_INDICES`** using **`EDGE_FACE_PAIRS`**.

6. **`Camera::direction()`** — returns **`Vec3::Z`** (fixed “into scene” direction per **`ortho_camera`** docs). **`wireframe::draw_edges`** calls **`camera.direction()`** and **`cube.visible_edges(forward)`** so culling matches the raster camera without a crate-root forward constant.

7. **API naming** — kept **`draw_edges`** (not **`draw_visible_edges`**) per user preference.

8. **Tests** — two **`visible_edges`** **count** tests in **`cube.rs`** with **hardcoded** forward vectors (no helper from eye positions): one along **`(0, 0, -1)`** expecting **12** segments on identity cube; one along **`(-1, -1, -1)`** expecting **9** (three edges of the “positive octant” hull culled when three mutual faces are back).

9. **`Cube::edges()`** removed — nothing outside the module needed all twelve unfiltered hull edges; **`draw_edges`** uses **`visible_edges`** only.

10. **Visibility** — **`CubeFace`**, **`FACES`**, and **`CubeFace`** methods/fields are **module-private**; public **`scene::cube`** surface is **`Cube`**, **`Edge`**, and **`visible_edges`**. **`refactoring_plan.md`** layout table updated to say topology stays inside **`cube.rs`**.
