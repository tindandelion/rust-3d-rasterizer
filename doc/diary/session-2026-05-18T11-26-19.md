## `FillQuad` primitive (`src/framebuffer/fill_quad.rs`)

- **TDD skill:** vertical slices (tracer bullet first, then more cases), behavior via public API + ascii art.
- **`FillQuad`:** `new([UVec2; 4], Rgb)`; **`corners`** stored as **`[Vec2; 4]`** (via **`UVec2::as_vec2`**) so edge vectors use signed **`Vec2`** math and **`perp_dot`** instead of hand-rolled **`i64`** cross code.
- **Inside test:** consistent winding via **`(b - a).perp_dot(p - a)`**; **`inside_convex_quad`** as a private method on **`FillQuad`** (later **`cross_o2d`** folded into **`perp_dot`** when moving to **`Vec2`**).
- **Implementation bug caught by tests:** inner bbox loop mistakenly used **`min_x..=max_y`** instead of **`min_x..=max_x`** (only a thin strip filled).
- **Bounding box:** computed in **`new`** as **`bounding_rect: [UVec2; 2]`** = **[min, max]** inclusive pixel corners; helper **`bounding_rect_from_corners(&[UVec2; 4])`** (integer min/max, no float floor/ceil needed).
- **`#[derive(Eq)]` dropped** from **`FillQuad`** when **`Vec2`/`f32`** entered the type.
- **Tests:** axis-aligned rect, rotated vertex order invariance, clip past buffer edge, slanted convex quad, degenerates (**all corners same point**, **quad collapsed to segment** with duplicate endpoints). Helper **`pts([(u32,u32);4]) -> [UVec2;4]`** in tests.
- **Exports:** **`FillQuad`** on **`lib.rs`**.

**Note on `UVec2` vs signed math:** **`UVec2`** subtraction wraps unsigned components; geometric deltas should use **`i32`/`i64`/`Vec2`**, not raw **`UVec2`** difference.

## `Cube` visibility (`src/scene/cube.rs`, `face.rs`)

- **`Cube::visible_faces(view_direction)`** → **`impl Iterator<Item = Quad>`** where **`Quad`** is four **`Vec3`** corners in facet winding (world space, same frame as **`vertices`**).
- **`iter_visible_faces`** (private): shared filter **`!face.is_back(view_direction)`** used by **`visible_edges`** and **`visible_faces`**.
- **`CubeFace::verts()`** → **`&[usize; 4]`** for index access.
- **`pub use face::CubeFace`** removed from **`cube.rs`** (callers use **`Cube`**, **`Edge`**, **`Quad`** at the scene API).
- **Tests:** visible face counts (front, arbitrary direction, after transform), one layout check for the −Z quad on the default cube.
